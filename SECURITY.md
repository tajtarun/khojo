# Security Policy

## Supported Versions

The project is currently maintained for the latest `main` branch and ongoing development work.

## Reporting a Vulnerability

Please do not open public issues for security-sensitive bugs.

Instead, report them privately through GitHub Security Advisories for this repository, or contact the maintainer directly through the repository owner profile.

When reporting a vulnerability, include:
- the affected component or route
- reproduction steps
- the expected vs. actual behavior
- any relevant environment details
- potential impact

We will acknowledge valid reports as quickly as possible and work toward a safe fix.
